# Reproducing the finite checks

These scripts check the explicit automata and supporting finite constructions in the paper. They use **Python 3.9 or later and only its standard library**; there are no packages to install. The publication package was checked with Python 3.14. The mathematical lower bound is proved in the paper, not by these finite computations.

Run the following commands from the repository root:

```sh
python3 audit_direction_upper.py --full
python3 audit_generation_check.py
python3 witness_verification.py
```

A successful run exits with status zero. A failed assertion stops the relevant script with a nonzero status. Do not use Python's `-O` option or set `PYTHONOPTIMIZE`: assertions are the checks, and each script refuses to run when they are disabled.

Each command prints its report and writes a copy in `results/`. That default location is resolved relative to the script, so the commands also work when invoked by absolute path from another directory. Use `--output PATH` to choose another report location; relative paths passed explicitly are relative to the current working directory.

## What each script checks

| Script | Scope | Expected result |
| --- | --- | --- |
| `audit_direction_upper.py --full` | Exhaustive small direction-determinate machines; state splitting for arbitrary small machines; 6,000 seeded random ternary machines. Each source answer is checked both by direct simulation and by configuration-graph reachability. The complement is checked for the opposite answer, halting, legal marker moves, and its state budget. | 850,552 machine instances and 4,960,600 source/input pairs; all pass. |
| `audit_generation_check.py` | Exhaustive enumeration of transformation pairs generated by the three letters, with the forward and backward composition orders used in the paper. | 477, 5,016, and 54,400 pairs at degrees `(3,3)`, `(3,4)`, and `(4,4)`, respectively. These are exactly all independent permutation pairs and all pairs of singular transformations. |
| `witness_verification.py` | The displayed source, its transformation formula, and its constructed halting complement on all ternary words of length at most seven, for eight degree pairs. | 26,240 comparisons; all pass. Every rejecting source run loops and every complement run halts. |

For a shorter upper-construction run, omit `--full`. This skips only the exhaustive three-state unary suite and leaves **30,328 machine instances and 859,480 source/input pairs**. The archived upper-construction baseline includes `--full`.

The exhaustive upper-construction suites include every initial and final state choice. For direction-determinate machines they also include every incoming-direction assignment, so the machine count is a count of instances, not of nonisomorphic automata. The random suite has seed `20261008`, uses 2 through 12 states, and checks every ternary word of length at most three plus ten sampled longer words per machine. Detailed sampling statistics can depend on Python's random-number implementation across versions; the fixed exhaustive counts and pass/fail assertions do not depend on random sampling.

The witness degree pairs are `(3,3)`, `(3,4)`, `(4,4)`, `(10,11)`, `(11,11)`, `(11,12)`, `(12,12)`, and `(12,13)`. The small pairs test the construction and composition conventions. They do not assert that the lower-bound theorem applies below its stated threshold.

## Comparing the recorded results

The `expected_*` files contain the recorded reports accompanying the reviewed source bundle. The generation report records the independently checked finite closure sizes. Regenerated reports go in the separate `results/` directory.

The two text reports should match their expected files exactly:

```sh
diff -u expected_audit_generation_check.txt results/audit_generation_check.txt
diff -u expected_witness_verification.txt results/witness_verification.txt
```

The upper-construction JSON includes elapsed wall-clock time, which naturally changes. Compare all other fields after a full run with:

```sh
python3 - <<'PY'
import json
from pathlib import Path

base = Path('.')
expected = json.loads((base / 'expected_audit_direction_upper.json').read_text())
actual = json.loads((base / 'results/audit_direction_upper.json').read_text())
expected.pop('elapsed_seconds', None)
actual.pop('elapsed_seconds', None)
assert actual == expected, 'Results differ; inspect the suite statistics.'
print('Upper-construction results match the recorded full-run baseline.')
PY
```

These checks corroborate the finite implementations. They do not enumerate all automata or all input lengths, prove the permutation-group lemmas, or establish the all-size lower bound. The scripts use the paper's **left-endmarker-only acceptance model**; the comparison with acceptance anywhere in the GMP model is a mathematical argument in the paper.
